## 🚀 Post Flow: 네이버 블로그 자동화 구현

### 1. 주요 작업 내용
오늘의 목표는 **네이버 블로그 자동 글쓰기 기능의 안정화**였습니다. 특히 에디터 진입 후 글이 써지지 않는 문제와 포커스 이동 문제를 집중적으로 다루었습니다.

#### ✅ 성과
- **진입 경로 최적화:** 
  - 기존의 직통 URL이 막히는 문제를 해결하기 위해, `블로그 홈` -> `글쓰기 버튼(Redirect URL)` 순서로 진입하는 인간 친화적인 경로를 구현했습니다.
  - 로그인 아이디와 블로그 식별자가 서로 다른 경우를 처리하도록 로직을 개선했습니다.

- **방해 요소 제거:**
  - 에디터 진입 시 뜨는 '이전 글 불러오기', '도움말' 팝업을 닫기 위해 `ESC` 키 연타 및 다양한 닫기 버튼 선택자(`.se-help-panel-close-button` 등)를 적용했습니다.

- **임시저장 기능:**
  - 실수로 원치 않는 글이 발행되는 것을 막기 위해, `발행` 버튼 대신 `저장` 버튼을 눌러 **임시저장** 상태로 글을 남기도록 수정했습니다.

- **안전장치 마련:**
  - 자동화가 실패하더라도 사용자가 이어서 작업할 수 있도록, 본문 입력 시도 후 내용을 **클립보드에 자동 복사**해두는 기능을 추가했습니다.

### 2. 발생한 이슈 및 현황 (Troubleshooting)

#### 🚧 이슈: 본문 포커스 실패 (Focus Lost)
- **현상:** 제목 입력 후 본문 영역을 클릭하거나 포커스를 주려 해도, 커서가 제목 입력창에 머물러 있어 **제목 칸에 본문 내용이 입력**되거나, **본문이 비어있는** 현상 발생.
- **시도한 해결책:**
  1. `Tab` 키 이동 -> 실패 (작동 안 함)
  2. JS 강제 포커스 (`document.activeElement.blur()`, `focus()`) -> 실패 (제목을 다시 잡거나 동작 안 함)
  3. 명시적 요소 클릭 (`.se-text-paragraph`, `.se-component-content`) -> 실패 (클릭 이벤트는 발생하나 포커스 이동 안 됨)
  4. **좌표 강제 클릭** (`page.mouse.click(x, y)`) -> 일부 환경에서 컨테이너 인식 실패.

- **현재 상태:**
  - 제목 입력과 임시저장은 정상 작동.
  - 본문 입력은 여전히 불안정하여, **클립보드 복사**로 대체된 상태.
