# 📅 일일 개발 리포트 (2026-02-04)

## 🚀 Post Flow: 네이버 블로그 자동화 완벽 구현 (Phase 3 완료)

### 1. 주요 작업 내용
오늘은 네이버 블로그 자동화의 가장 까다로운 문제들을 모두 해결하고, **이미지 다중 업로드 및 배치**까지 안정화시켰습니다.

#### ✅ 성과 (Achievements)
1.  **에디터 본문 포커스 해결:**
    *   HTML 정밀 분석을 통해 `[data-a11y-title="본문"]` 선택자를 발굴, 제목/본문 입력 오류를 원천 차단했습니다.
2.  **팝업/오버레이 완벽 대응:**
    *   '작성 중인 글' 팝업, '도움말' 팝업, 그리고 **'사진 배치 방식 선택' 팝업**까지 모든 돌발 상황을 처리하는 로직을 추가했습니다.
    *   특히 HTML 덤프(`debug_popup.html`)를 통해 "개별 사진" 버튼의 정확한 트리거(`label:has-text('개별사진')`)를 찾아내어 다중 이미지 업로드 시 멈춤 현상을 해결했습니다.
3.  **이미지 업로드 고도화:**
    *   `kakotalk_*.jpg` 등 실제 이미지를 인식하여 최대 3장까지 한 번에 업로드하는 기능을 구현했습니다.
    *   백엔드(`backend/uploads`) 절대 경로 저장 로직을 수정하여 프론트엔드 연동 시 경로 꼬임 문제를 해결했습니다.
4.  **프론트엔드 연동 준비:**
    *   Flutter 앱에서 백엔드로 이미지 경로를 전달하는 로직(`api_service.dart`, `post_provider.dart`)을 연결 완료했습니다.

### 2. 기술적 교훈 (Lessons Learned)
- **Playwright 디버깅:** 눈에 보이는 버튼 텍스트가 실제 클릭 가능한 요소가 아닐 수 있습니다(예: `input` vs `label`). 이럴 땐 반드시 `HTML Dump`를 떠서 내부 구조를 확인해야 함을 재확인했습니다.
- **경로 관리:** 백엔드 서버 실행 위치에 따라 상대 경로가 달라지는 문제를 방지하기 위해, 항상 `os.path.abspath(__file__)` 기준의 절대 경로를 사용해야 합니다.
