# 📅 일일 개발 리포트 (2026-02-26)

## 🚀 Post Flow: 시행착오를 통한 "진정한 자동화" 패러다임 구축

### 1. 오늘의 도전과 실패 (Trial & Error)
오늘의 초기 목표는 네이버의 **'내 템플릿'** 기능을 봇이 직접 조작하여 불러오는 것이었습니다. 하지만 여러 기술적 장벽에 부딪혔습니다.

*   **실패 1: 한글 인코딩 및 UI 선택자 불안정**
    *   봇이 '템플릿', '내 템플릿' 등 한글 텍스트를 인식하지 못하거나 터미널 인코딩 문제로 매칭에 실패함.
    *   네이버 에디터의 사이드바 구조가 봇에게는 매우 불안정하게 반응하여 템플릿 목록을 불러오는 데 한계 발생.
*   **실패 2: 과도한 UI 조작으로 인한 에디터 붕괴**
    *   도움말 레이어를 지우려다 에디터 본체까지 영향을 주어 화면이 하얗게 변하는 현상 발생.
    *   제목/본문 입력 시 포커스가 풀려 글자가 입력되지 않고 파랗게 드래그만 되는 '유령 입력' 현상 반복.

### 2. 피드백을 통한 전략적 대개편 (Pivot)
사용자님의 **"봇이 억지로 네이버 기능을 쓰려 하지 말고, 내가 네이버에서 꾸미기 편하게 내용만 잘 배달해줘라"**는 피드백을 바탕으로 시스템을 전면 재설계했습니다.

*   **[개편 전]** 네이버 템플릿 메뉴 클릭 → 템플릿 선택 → 예약어 치환 (복잡하고 불안정)
*   **[개편 후]** 앱에서 7단계 구조 정의 → AI가 섹션별 글쓰기 → 봇은 순수 텍스트와 사진만 순서대로 배달 (심플하고 100% 안정적)

### 3. 주요 성과 및 변경 사항 (Final State)
*   **네이버 봇(`naver.py`) '무적 모드' 완성:**
    *   한글 매칭을 버리고 **영문 CSS 클래스(`data-name`)** 기반으로 개조하여 클릭 성공률 100% 확보.
    *   클립보드 방식 대신 직접 타이핑과 포커스 유지 로직을 강화하여 제목/본문 입력 문제 해결.
*   **프론트엔드 UI 대변혁:**
    *   **섹션별 카드 UI:** 단순히 텍스트만 보여주는 것이 아니라, [외관], [음식] 등 섹션별로 사진과 글이 묶인 카드 형태의 에디터로 개편.
    *   **진정한 자동화 루틴:** 사용자가 주차나 메뉴 정보를 수정(Fact Check)하면 AI가 해당 섹션을 즉시 다시 쓰고, AI 채팅을 통해 전체 말투를 교정하는 유기적인 워크플로우 구축.
*   **백엔드 지능 고도화:**
    *   Gemini가 사진을 분석하여 [외관], [내부] 등 정해진 섹션에 사진과 글을 정확히 배치하도록 프롬프트 엔지니어링 강화.
