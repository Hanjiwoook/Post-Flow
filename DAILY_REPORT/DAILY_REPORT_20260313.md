- 기존 '분류(1회) + 생성(1회)' 호출 구조를 **'분류 & 생성 동시 처리(1회)'**로 통합.
- **결과:** API 쿼터 소모량 50% 절감, 전체 분석 시간 단축, 사진과 본문의 지능적 연계 강화.

- **BOT:** 섹션 제목의 메뉴명을 인식하여 해당 메뉴 사진만 본문 사이에 쏙쏙 골라 넣는 정밀 매칭 로직 구현.
- **결과:** '사진-설명-사진-설명'의 고퀄리티 포스팅 구조 자동 완성.
