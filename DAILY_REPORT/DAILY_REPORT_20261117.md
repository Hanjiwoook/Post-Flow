### 1. [Backend] 검수 반영 고쳐쓰기 `/revise` (`d3591cf`)

- **AI는 글 블록 단위로만 교체한다.** 응답은 `{블록 번호, 고친 내용}` 목록이고, 사진 · 지도 · 인용구 블록은 코드가 원래대로 둔다. 고쳐 쓰다가 사진이 빠지거나 순서가 바뀌는 일이 구조적으로 생기지 않는다(예전에 사진이 사라지는 버그를 겪었다).

- "모름" 같은 답은 지시문에서 뺀다. 근거가 없어서 반영하지 못한 지적은 "반영 못 함"으로 남긴다.

### 4. [Bot] 발행 봇 (`0b32bf1`, `3adeb7b`, `92c0312`)
- **개인정보 버그:** 예전 Safety Net이 글에 없는 사진을 모두 글 끝에 올렸다. AI가 일부러 뺀 **영수증 사진까지 올라가는 문제**였다. 이제 올리지 않고 번호만 로그에 남긴다.
- **로그인:** 네이버 로그인 버튼 id가 바뀌어 봇이 멈췄다. 고친 뒤에도 매번 자동 로그인하면 보안 확인에 걸려 글쓰기 화면이 로그인 페이지로 돌아갔다. 그래서 **사람이 한 번 직접 로그인해 저장한 상태로 시작**하게 바꿨다. 비밀번호와 클립보드를 더 이상 쓰지 않는다. 세션 파일은 gitignore에 넣었다.
- **편집기 조사:** 메뉴를 열어 보기만 하는 조사 스크립트로 인용구 스타일 · 글씨 크기 · 장소 팝업의 실제 이름표를 찾았다. 추정했던 장소 검색 결과 이름표는 둘 다 틀렸었다.
- **서식 수정:**
  - 지도: 장소 검색 → 주소가 맞는 지점 → 추가. 검색창이 React 입력창이라 값을 한 번에 채우면 검색이 실행되지 않아, 사람처럼 타이핑 후 Enter.
  - 인용구: 가게 이름은 기본, 가게 정보는 세로줄 스타일.
  - 가운데 정렬: 정렬 버튼이 드롭다운으로 바뀌어 **예전 코드는 정렬을 한 번도 못 하고 있었다.** 예전 테스트 블로그는 블로그 기본 정렬이 가운데라 된 것처럼 보였다.
