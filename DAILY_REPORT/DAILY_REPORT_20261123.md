## 🐞 작업 중 실수와 교훈
- **창이 열리면 어두운 막이 버튼을 가린다:** 발행 창을 Esc나 `locator.click()`으로 닫으려다 30초씩 멈췄다. HTML에서 `dimmed` 막을 찾고, 마우스로 버튼 자리를 직접 눌러 해결했다.
- **가짜 서버의 한계를 먼저 말하기 (또):** "이력에서 다른 글을 열어 보라"고 안내했는데 가짜 서버 이력 글은 1개뿐이라 작업본이 2개에서 안 늘었다. 앱 문제가 아니었다.
- **heredoc의 `\n` (또):** 파이썬 스크립트로 코드를 넣다가 문자열의 `\n`이 실제 줄바꿈이 되어 문법 오류. 파일이 CRLF여서 `\r\n`이 문자열 안에 들어간 경우도 있었다. `chr(92)`로 백슬래시를 만들어 고쳤다.
- **한 파일에 두 변경이 섞이면 커밋을 나누기 어렵다:** 정리(`applyTemplate` 삭제)와 저장 기능이 같은 파일이라 한 커밋으로 묶었다.
