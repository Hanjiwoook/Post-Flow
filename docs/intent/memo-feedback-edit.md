# 의도: 메모로 피드백하고 부분만 고치기

확정: 2026-11-20 (`interview-me` 인터뷰)

## 목표 (Why)
- 실제로 써 보니 검수 지적이 맞는데도 고칠 방법이 없었다.
- 전체 고쳐쓰기는 마음에 드는 부분까지 바뀔까 봐 싫다. 11/18에 "AI에게 수정 요청"을 지운 이유도 이것이다.
- 원하는 곳만, 앞뒤 흐름은 자연스럽게 고쳐서 임시저장 전에 글을 완성하고 싶다.

## 흐름
1. 편집 화면에서 글을 읽다가 드래그해서 메모를 남긴다("이렇게 바꿔 줘", "이건 빼도 돼").
2. 검수 지적은 해당 블록에 메모로 미리 달린다. 내 메모와 색으로 구분하고, 체크·삭제·수정할 수 있다.
3. [AI에게 확인]을 누르면 메모마다 AI가 두 가지를 준다.
   - 고친 안: 바뀌는 범위 전체의 "원래 → 고친 글"
   - 의견: 왜 그렇게 고쳤는지(예: "앞 문장도 같이 다듬었어요")
4. 메모별로 [승인], [거절], [답장해서 다시 요청] 중 하나를 고른다.
5. 승인한 안만 미리 본 그대로 글에 들어간다. 승인할 때 AI를 다시 부르지 않는다.
6. 여러 번 반복할 수 있다. 지금의 "고쳐쓰기는 한 번만" 제한은 메모 방식에는 적용하지 않는다.

## 완료 기준 (Success)
- AI가 고칠 수 있는 범위는 메모 단 블록과 바로 앞뒤 글(text) 블록까지다. 블록 수는 바뀌지 않는다.
- 바뀌는 범위는 안에 전부 보인다. 안에 없는 블록은 한 글자도 바뀌지 않는다(코드로 검증).
- 검수 지적을 실제로 고칠 수 있다.

## 제약 (Constraint)
- 12/17 전에 완성한다.
- 완성도를 위해 토큰이 더 드는 것은 감수한다.
- 지금 검수 기능(점수·질문)은 그대로 쓰고, 지적 사항만 메모로 옮긴다.

## 하지 않을 것 (Out of scope)
- 글 전체 고쳐쓰기 개선
- 맛 표현 여러 개 선택 (작고 따로인 문제, 다음 차례)
- UI 사용감 전반 손보기 (따로 인터뷰)
- 사진·지도·인용구 블록 수정
- 메모 단 블록과 바로 앞뒤 글 블록 밖의 수정
